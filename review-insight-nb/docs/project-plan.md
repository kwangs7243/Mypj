# Project Plan

## Working Title

Review Insight NB

## Purpose

Naive Bayes 모델을 활용해 한국어 리뷰 텍스트의 긍정/부정 감성을 분석하는 웹서비스를 만든다.

이 프로젝트는 포트폴리오 목적뿐 아니라, AI와 협업하면서 개발자가 프로젝트 전체를 얼마나 통제할 수 있는지 경험하기 위한 학습 프로젝트다.

## MVP

1. 리뷰 데이터셋 준비
2. 텍스트 전처리
3. Naive Bayes 모델 학습
4. 모델 저장
5. FastAPI API 구현
6. React 입력 화면 구현
7. 프론트엔드와 백엔드 연동
8. README 정리

## Expansion Candidates

- CSV 업로드 분석
- 여러 리뷰 일괄 예측
- 긍정/부정 비율 차트
- 단어 빈도 시각화
- 분석 결과 다운로드
- DB 저장
- 배포

## Completion Standard

1차 완성 기준은 로컬 웹 화면에서 리뷰를 입력했을 때 모델 예측 결과가 정상 출력되는 것이다.
