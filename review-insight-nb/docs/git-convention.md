# Git Convention

## Commit Message Style

커밋 메시지는 다음 형식을 기본으로 사용한다.

```text
type: 작업 요약
```

Examples:

```text
chore: 프로젝트 초기 구조 생성
feat: 리뷰 예측 API 추가
feat: 모델 학습 스크립트 추가
fix: 빈 리뷰 입력 예외 처리
docs: 프로젝트 계획 문서 정리
refactor: 감성 예측 로직 서비스로 분리
```

## Why

- 커밋 단위와 작업 성격을 빠르게 구분하기 위해 사용한다.
- 짧은 제목으로 작업 흐름을 추적할 수 있게 한다.
- 포트폴리오와 면접에서 형상관리 기준을 설명할 수 있도록 한다.

## Common Types

- `feat`: 새로운 기능 추가
- `fix`: 버그 수정
- `docs`: 문서 수정
- `style`: 코드 의미 변경이 없는 포맷 수정
- `refactor`: 기능 변경이 없는 구조 개선
- `test`: 테스트 추가 또는 수정
- `chore`: 설정, 초기 구조, 빌드 보조 작업
