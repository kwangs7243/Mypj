# Portfolio Summary Draft

## One-Line Summary

Naive Bayes 알고리즘을 활용해 한국어 리뷰 텍스트의 긍정/부정 감성을 예측하는 웹서비스입니다.

## Description

scikit-learn으로 리뷰 텍스트를 벡터화하고 Naive Bayes 모델을 학습한 뒤, FastAPI 서버에서 학습된 모델을 로드해 예측 API를 제공합니다. React 프론트엔드에서는 사용자가 리뷰를 입력하면 API와 통신해 예측 결과와 확률을 확인할 수 있도록 구현합니다.

## Skills Demonstrated

- 텍스트 전처리
- 머신러닝 모델 학습 및 평가
- FastAPI 기반 API 설계
- React 기반 프론트엔드 구현
- 프론트엔드와 백엔드 연동
- 프로젝트 문서화
- AI 협업 기반 개발 통제
